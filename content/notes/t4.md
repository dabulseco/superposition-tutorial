PAGE NOTES: Topic 4 — Phi-Bit Systems

- System: a chain of 12 weights. Each is joined to its neighbors by springs
  and tied to a wall by a side spring. A driver shakes one end. Waves
  travel along it much as sound travels through air.
- The two basic states: State 0 is a wave traveling LEFT, State 1 is a wave
  traveling RIGHT. A superposition is any combination:
    u(x, t) = a_L cos(k x + omega t) + a_R cos(k x - omega t + delta)
  a_L and a_R are amplitudes (the LEFT and RIGHT sliders, 0 to 100%) and
  delta is the relative phase slider.
- Status box: only left = Pure State 0; only right = Pure State 1; equal
  amplitudes = 50/50 Superposition (Standing Wave); unequal = Uneven Mix
  (a "lumpy" traveling wave that drifts toward the stronger wave's
  direction); both zero = no waves.
- Standing wave: with a_L = a_R = a,
    u = 2a cos(k x + delta/2) cos(omega t - delta/2).
  The still points (nodes) are where cos(k x + delta/2) = 0. They never
  move in time. Changing delta slides them along the chain by
  delta / (2k); the wave stays a standing wave. This is the wave
  counterpart of the angle phi on the qubit's sphere.
- Amplitude vs. power: power goes as amplitude squared. "Share of State 1"
  = a_R^2 / (a_L^2 + a_R^2), the same formula as a qubit's probability of
  |1>. Example: amplitudes 80% and 60% give powers 0.64 and 0.36 and a
  share of 36%.
- On the sphere: theta = 2 arctan(a_R / a_L), phi = delta.
- By default the frequency slider only changes how fast the animation
  runs, as in the original primer. With "Go deeper: a real chain" on, the
  frequency sets the wavelength through
    omega^2 = k0/m + (4K/m) sin^2(q a / 2)
  (m = 1, K = 4, k0 = 1 here), so only frequencies from 1.0 to about 4.1
  can travel. Below 1.0 the side springs hold the weights too firmly.
- Same as a qubit: two basic states, two amplitudes, a relative phase, the
  same sphere. Different from a qubit: this is a classical wave. Both
  waves can be observed at once, and observing changes nothing. A qubit
  measurement gives only one result and the state snaps to it.
- Superposition is not only for tiny quantum objects: waves on springs,
  sound, and light all superpose.
